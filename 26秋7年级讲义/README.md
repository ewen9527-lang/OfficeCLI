## 迭代要点（对照需求逐项落实）

- **内容知识点**：冠词按「a/an 看读音、the 独级乐序姓特、零冠词」体系重构；名词辨析补充易混词
  （advice/suggestion、clothes/clothing、people/peoples）；适配新课标「友谊·品格 / 亲情·陪伴」话题词汇。
- **新课标词汇（核心词汇）**：每讲精选 **5 个本讲篇章词**，在【25秋】讲义原词基础上扩充，
  **避开【25秋】7年级练习册同课次词汇**（如练习册 L1 的 choose/remember/honest、L2 的 think/answer/bring
  均已规避），优先 **7 年级下学期常考高频词**；形式采用【26暑】8A「核心词汇」**音·形·意·用·拓**
  五维体例（含「单词 | 构成 | 词性 | 含义」拓展表）。
- **例题 & 习题**：保留各地中考/期中真题，按 ★/★★/★★★ **分层设题**；新增完形四步法、细节题三步法。
- **结构排版**：按新大纲的「阅读讲 / 完形讲 / 写作讲」三讲循环重排，每讲 Part 顺序与大纲一致。
- **语言表述**：统一术语（音素、特指、泛指），中英对照、口诀化表达，贴合 7 年级认知。
- **视觉呈现**：主色由 25 秋的绿色自然系换为 **青绿 (teal) + 暖橙 (orange)** 现代版式；
  每讲整页封面大数字水印、图标小标题、青绿横幅 Part 标题、米黄/青绿高亮框、页脚跑标 + 页码。
- **课堂适配**：每讲新增「课堂小游戏 / 写作工坊」互动环节。
- **听力配套**：每个含听力的讲次（第 1–6、8–16 讲）均附「🎧 听力录音原文（Tapescript）」，
  与题目、答案一一对应，可直接读稿放听。
- **重难点标注**：红色「避坑提示」框 + 橙色「口诀总结」框，强化易错点与解题技巧；每讲末附**参考答案与解析**。

## 文件说明

- `jiangyi_lib.py` —— 排版样式库（配色、字体、封面、Part 横幅、考点、例题、高亮框、表格、
  核心词汇词条 `core_word`、页脚等）。6 个输出复用同一套样式，保证风格统一。
- `build_out1.py … build_out6.py` —— 6 个输出（每 3 讲）的内容与构建脚本。

> **内容来源**：第 1–13 讲的语法 / 阅读 / 完形 / 作文素材主要迭代自【25秋】7年级讲义对应课次；
> 一现/现进、祈使句、特殊疑问句、补全对话等新大纲新增板块由人工按新课标编写，配套语篇为
> 适配 7 年级认知自编的高频话题篇章。词汇均按所映射课次**避开练习册词**、优先 7 下高频。

## 生成 / 重新生成

```bash
cd 26秋7年级讲义
for i in 1 2 3 4 5 6; do python3 build_out$i.py; done   # 一次性生成 6 个 Word 文件
```

依赖：`python-docx`（`pip install python-docx`）。

## 查看与校验

```bash
officecli validate "【26秋】7年级讲义（第1-3讲）.docx"     # 结构校验：no errors found
officecli view "【26秋】7年级讲义（第1-3讲）.docx" screenshot --page 1-12 -o preview.png
```

> **关于页码与封面**：每讲为独立「分节」，封面占整页（首页页脚留空），正文页脚为
> 「主题跑标 ｜ P.页码」（PAGE 域）。officecli 的 HTML 预览**不分节、不显示各节页脚/页码域的计算值**，
> 属预览器限制；在 Word / WPS 中打开即按分节正确分页，页脚主题与页码正常显示
> （首次打开按 **F9** 可刷新页码域）。
